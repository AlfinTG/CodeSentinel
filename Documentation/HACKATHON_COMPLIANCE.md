# Hackathon Compliance Checklist

This is a checklist, not organizer confirmation. Re-check current official rules and submission page immediately before submission: https://nebiusglobalaihackathon.devpost.com/rules

Verify deadline/timezone; required platform/model/provider path and model eligibility; public source repository/license; demo URL/recording and evaluator access; track requirements and judging criteria.

## Track fit
Choose based on demonstrated behavior, not product naming. If selecting a coding/agentic engineering track, demonstrate actual candidate code change plus isolated tests if required by current rules. If delivered product only ingests GitHub events, runs tests and diagnoses evidence, confirm that it fits the selected track. Inference through Token Factory is not the same as executing code inside Token Factory.

Keep exact model ID, provider disclosure, live-call proof, reproducible setup, public repository/license and demo flow. Do not submit fake metrics or describe unimplemented features as complete.
